# Google Interview Roadmap

This is a web page that provides a 1-year study plan for Google software engineer interviews.

## How to use

1.  Open the `index.html` file in your browser.
2.  Follow the study plan and check off the tasks as you complete them.
3.  Your progress is saved in your browser's local storage.
4.  You can export your progress as a JSON file and import it later.
